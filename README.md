# Kai's Stories

Medium stories hosted via GitHub Pages.

## How to add a new story

1. Create a new `.md` file at the root (e.g., `my-new-story.md`)
2. Add frontmatter at the top:
   ```markdown
   ---
   title: My New Story
   layout: page
   ---
   ```
3. Add a link in `index.md`
4. Push — GitHub Pages builds automatically

## URLs

Each `.md` file becomes a page:
- `openclaw-career-copilot.md` → `/openclaw-career-copilot`
